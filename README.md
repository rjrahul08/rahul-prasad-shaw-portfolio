# Portfolio Next.js Migration

This folder contains the complete source code for the Next.js version of the portfolio.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser.

## Structure

- `src/app`: App Router pages and layout.
- `src/components`: React components organized by type.
- `src/hooks`: Custom animations hooks (GSAP).
- `src/data`: Content source of truth.
